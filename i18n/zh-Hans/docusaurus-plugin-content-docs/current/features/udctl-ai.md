# udctl.com 提供的 AI

:::note 尚未开放
udctl.com 提供的 AI 尚未开放。开放之前，点「开启」会提示「连接 udctl.com 没有成功」,不会开启任何东西;这期间可以先用你自己的 API key。开放之后，同一个按钮直接可用，不需要更新应用，届时这条说明会撤掉。
:::

Alfred 要有 AI 模型才能回答。桌面版或单人自托管实例上还没有自己的模型时，可以不填 API key,直接开启 udctl.com 提供的 AI。不用注册。

它默认关闭。开启之前，应用不向 udctl.com 发送任何内容。

## 谁能用，在哪里开

- 只对 Personal 档：桌面版和单人自托管实例。Pro 和 Max 服务器不提供。
- 凡是 Alfred 没有模型的地方都会出现：首次引导里选了「还没有，先聊天」之后、对话输入框上方、Alfred 快捷输入，以及还没配置提供商时的 **设置 > AI 与模型**。
- 每处都是同一块提示：下面两条说明、**开启** 按钮和 **用我自己的 API key** 按钮。

## 开启前要知道的两条

1. **每天有额度上限。** 用完后当天不能再用，次日重置，重置时间是 UTC 零点。Alfred 回答一次可能要调用模型好几次。开启期间，对话输入框上方会显示剩余，例如「经由 udctl.com · 今日剩余 27/30」。另外还有按网络计的每日上限和 udctl.com 当天的总额度;任何一个用完，Alfred 会在线程里说明是哪一个。
2. **对话会离开本机。** 开启后，你和 Alfred 的对话，以及 Alfred 为回答而读取的卡片内容，会发送到 udctl.com,再转给模型服务商(Anthropic)生成回答。

## 发送什么，发到哪

只有三种请求会发到 udctl.com,而且只在开启期间:

| 请求 | 什么时候 |
|---|---|
| 登记 | 点 **开启** 时一次。udctl.com 发回一个匿名访问令牌，此后这台安装就用它。 |
| 消息 | Alfred 回答你时。请求里带着你的对话和 Alfred 读取的卡片。 |
| 用量 | 打开对话或设置页时、开启成功后、一次回答结束后。 |

没有定时器，没有后台心跳。请求里不带机器码、安装 id、应用版本、本机账号名;唯一的身份就是那个匿名令牌。udctl.com 的访问日志会记录来源 IP 和请求时间，不记录对话内容。

只有 Alfred 和对话里的回答会用它。其他 AI 功能(对任务、笔记、图片的 AI 操作，识别小票，定时 AI 任务)不用它，仍然需要你自己的提供商。

## 怎么关

到 **设置 > AI 与模型**,在「udctl.com 提供的 AI」那一行点 **关闭**。本机保存的访问令牌一并删除，之后不再向 udctl.com 发送任何请求。再次开启会重新登记。

## 换成自己的 API key

在 **设置 > AI 与模型** 里添加你自己的提供商(见 [配置 AI 提供商](../howto/config-ai-provider.md))。你自己的模型自动优先:udctl.com 那一行留在列表里，排在后面作备用，对话输入框上方变成「使用你自己的模型 · 不占官网额度」。不需要去关掉 udctl.com 的选项;只有不想留备用时才关。
