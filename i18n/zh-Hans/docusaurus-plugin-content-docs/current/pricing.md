# 定价

udctl 自部署许可证按团队规模分档定价,不按人头计费。选中团队所在的档位,账单就是那一个数。档位内加人不加钱,账单里也没有任何一行写着「每人每月」。

## 四个档位,价格以美元计

| 档位 | 团队规模 | 价格 | 年付 | |
|------|----------|------|------|---|
| **个人** | 一个人用 | 免费 | | 永久免费,无需许可证。 |
| **小团队** | 3 人及以下 | 免费 | | 整队一张免费许可证。 |
| **团队** | 20 人及以下 | US$49 / 月 | 或 US$490 / 年 | 整套部署一个价。 |
| **无限** | 人数不设上限 | US$149 / 月 | 或 US$1490 / 年 | 整套部署一个价。 |

年付按十个月计,等于送两个月。价格以美元计。

## 按档位,不按人头

每张许可证覆盖一个规模档位,一个固定价格。团队从 4 个人涨到 20 个人,一分钱不多花;只有跨进下一个档位,数字才会变。账单不会因为多来了一个人而变长。
